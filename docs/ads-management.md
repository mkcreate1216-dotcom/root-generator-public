# 広告管理・設定変更マニュアル

たびろーむ（TabiRome）の広告バナーやプロモーション枠の追加・編集・掲載位置の切り替え、サイズ変更を行うための手順書です。

本システムは、**ブラウザ上の管理・プレビューツール（`/admin/ads`）**で直感的にバナーを作成・確認し、生成されたコードを設定ファイル（`src/config/ads.ts`）に反映する**パターンA（静的設定管理方式）**を採用しています。データベースや外部認証に依存しないため、改ざんリスクがなく安全に運用できます。

---

## 1. 概要・ファイル構成

| 役割 | パス / URL | 説明 |
| :--- | :--- | :--- |
| **管理・プレビュー画面** | `http://localhost:4321/admin/ads`<br>*(本番: `/admin/ads`)* | A8タグの自動解析、ライブプレビュー、掲載枠アサイン、サイズ変更、新規枠作成、設定コード生成を行う画面です（検索エンジン除外 `noindex` 設定済み）。 |
| **広告設定ファイル** | [`src/config/ads.ts`](../src/config/ads.ts) | 登録済み広告アイテム、掲載枠の割り当て、サイズ定義を管理するTypeScriptファイルです。 |
| **広告表示コンポーネント** | [`src/components/TravelBookingAd.astro`](../src/components/TravelBookingAd.astro) | 各ページで広告枠を描画するコンポーネントです。 |

---

## 2. 標準で用意されている掲載枠（スロット）

| スロットID | 掲載位置 | デフォルト状態 | 説明 |
| :--- | :--- | :---: | :--- |
| `itinerary_bottom` | 行程表（タイムライン）直下 | **ON** | 旅程作成・閲覧時に表示されるメイン枠です。トップページ（`/`）および共有ページ（`/p/[planId]`）に配置されています。 |
| `footer_top` | フッター直上 | **OFF** | ページ最下部のフッター手前に表示される補助枠です。管理画面からONに切り替えると全ページで有効化されます。 |
| `lp_hero_bottom` | LPヒーロー直下 | **OFF** | LPのタイトル・特徴と入力バーの間に表示されるPR枠です。 |

- **広告が0件、または枠がOFFの場合**: コンポーネント自体がDOMを出力せず、完全に非表示になります。
- **広告が1件の場合**: 単独バナーとして表示され、左右の切り替え矢印やドットは非表示になります。
- **広告が複数件の場合**: 6秒間隔の自動ローテーションカルーセル（左右手動ボタン・ドット・ホバー時一時停止対応）として動作します。

## 3. サイズ変更機能の使い方

各掲載枠ごとに、掲載したいバナーのサイズ（アスペクト比）に合わせて自由にサイズを変更できます。

### 選択可能なプリセット
- **コンパクト (320 × 60 px)**: 現在の標準サイズ。タイムラインの邪魔にならない省スペース型。
- **モバイルラージ (320 × 100 px)**: スマホで視認性が高く、クリック率を高めたい場合におすすめ。
- **レクタングル (300 × 250 px)**: アフィリエイトで最も一般的な四角形バナー。高単価な宿泊・ツアー案件に最適。
- **リーダーボード (728 × 90 px)**: PCワイド閲覧向けの横長バナー。
- **カスタム指定**: 幅（px）と高さ（px）を自由に入力可能。

### サイズ変更の手順
1. 管理画面（`/admin/ads`）の「掲載枠の設定 ＆ サイズ変更」エリアを見る。
2. 対象の枠の**「表示サイズ」**ドロップダウンから希望のプリセット（例: `レクタングル (300×250)`）を選択。
   - カスタム指定を選んだ場合は、右横に表示される幅・高さの入力欄に数値を入力します。
3. 左側の「掲載枠ライブプレビュー」で、バナーが指定したサイズで綺麗に収まっているか確認。
4. 「コードをコピー」を押して `src/config/ads.ts` にペーストすれば完了です。

## 4. 広告枠をレイアウト上に増やす方法

管理画面から自由に新しい掲載枠（カスタム枠）を作成し、サイト上の好きな場所に追加できます。

### 手順
1. 管理画面右上の**「＋ 掲載枠を新規作成」**ボタンをクリック。
2. 以下の項目を入力して「＋ 枠を作成」をクリックします：
   - **スロットID**: 半角英数とアンダースコア（例: `sidebar_right` や `plan_detail_bottom`）
   - **枠の表示名称**: 管理用の名前（例: `サイドバー枠`）
   - **アイコン**: PR表記の左に添える絵文字（例: `🏨` や `🚗`）
   - **PR見出しラベル**: ユーザーに表示する見出し（例: `おすすめの宿泊プラン`）
   - **初期サイズ**: コンパクト、レクタングル等を選択
3. 作成した枠カードの右下にある**「`<TravelBookingAd slotId="スロットID" />` をコピー」**をクリック。
4. 追加したいAstroファイル（例: `src/pages/index.astro` やレイアウトファイル等）の好きな位置にペーストします。
5. 管理画面で「コードをコピー」して `src/config/ads.ts` を更新・コミットします。

## 5. 基本の操作手順（4ステップ）

```text
[1. タグ貼付け・自動解析] ➡️ [2. 掲載枠アサイン・サイズ調整] ➡️ [3. プレビュー確認] ➡️ [4. コードをコピー＆保存]
```

### ステップ1: 広告バナーの追加（A8タグの自動入力）
1. A8.netなどのASP管理画面から、バナーのHTMLコード（`<a href="...">...</a>`）をコピーします。
2. 管理画面右側の**「A8などのHTMLタグを自動解析」**のテキストエリアに貼り付けます。
3. **「⚡️ タグを解析してフォームに入力」**ボタンをクリックします。
   - リンク先URL、バナー画像URL、サイズ（幅・高さ）、altテキスト、計測用1x1画像が自動抽出されます。
4. 管理名称（例: `じゃらん 宿泊 300x250`）を入力し、カテゴリを選択したら、**「＋ 広告リストに保存」**をクリックします。

### ステップ2: 掲載枠への割り当て ＆ サイズ設定
- 各枠の「表示する広告の選択」で、出したい広告にチェックを入れます。
- 必要に応じて「表示サイズ」を変更します。

### ステップ3: 左側のライブプレビューで確認
画面左上の**「掲載枠ライブプレビュー」**で、実際の画面と同じ見た目・挙動をテストします。
- タブをクリックして各枠の表示を切り替えられます。
- 左右矢印やドットをクリックして動作を確かめます。

### ステップ4: 設定コードのコピーと反映
1. 画面左下の黒い枠内にある**「コードをコピー」**ボタンをクリック。
2. エディタで [`src/config/ads.ts`](../src/config/ads.ts) を開きます。
3. 内容を**すべて選択して上書き貼り付け（ペースト）＆保存**します。
4. ターミナルでコミット＆プッシュ（デプロイ）すれば完了です。

## 6. トラブルシューティング

### Q. レクタングル（300×250）バナーが枠からはみ出る
- バナー画像のサイズに合わせて、枠のサイズプリセットを「レクタングル (300×250)」または「カスタム指定」で幅300 / 高さ250に設定してください。
- バナー画像は枠内で自動的に `object-contain`（比率を保ったまま中央揃え）で収まるように設計されています。

### Q. 追加したカスタム枠が表示されない
- その枠の `enabled: true` になっているか確認してください。
- 枠に割り当てられた広告が1つ以上「有効」になっているか確認してください。
- Astroファイル内に `<TravelBookingAd slotId="枠ID" />` が正しく配置されているか確認してください。
