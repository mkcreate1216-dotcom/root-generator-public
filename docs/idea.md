＜プロンプト＞
以下のUI修正およびスタイルの調整をお願いします。
本アプリケーションのコアバリューは「ルート検索」であり、時間管理やメモなどの情報伝達はあくまで「サブ機能」です。この主従関係が視覚的・機能的に明確に伝わるUIへ見直します。

1. 旅行名切り替えアイコンのホバー挙動修正
現状の事象: マウスホバー時にアイコンが下側に移動してしまい、操作性が著しく低下している。

修正内容: ホバー時でも要素の位置（座標）が絶対にずれないよう固定してください。

transform: translateY(...) や、ホバー時にのみ適用されている margin / padding / border の差分がないか確認し、位置の移動を無効化してください。

2. 未保存ステータス（保存マーク）の配色変更
現状: 「黒」に「オレンジ」

修正内容: 「白」に「オレンジ」の配色に変更してください（例: 白ベースの背景/テキストにオレンジのアイコンやアクセントカラー）。

3. メモ追加UI等のシンプル化（リッチUIの抑制）
現状: メモ追加等のUIコンポーネントがリッチ（装飾的・大がかり）になりすぎており、画面内で過剰に主張している。

修正内容: 装飾や過剰な要素を削ぎ落とし、初期のシンプルなUIへ戻してください（ミニマルな入力欄・控えめなボタン等）。

4. UI全体の視覚的優先度（情報設計）の再整理
主機能（Primary）: ルート検索

最も目に入りやすく、迷わず最短ステップで操作できる導線・レイアウトを維持・強調する。

サブ機能（Secondary）: 時間管理・メモ・情報伝達

主機能の視認性や操作性を妨げないよう、サイズ・コントラスト・配置を控えめに抑える。
